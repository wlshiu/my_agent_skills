# 職涯諮詢階段模板與引導話術庫

## Phase 1: 身分對齊與目標定位模板

+ **開場白設計**:

    ```
    您好!我是您的資深職涯教練。 為了能最精準地協助您,我們將透過幾個階段來逐步梳理您的方向。
    首先,想請教您目前正處於哪一種轉職或求職情境?(例如: 跨領域轉職、內部晉升/中高階跳槽、跨國遠距或海外求職?)
    您目前最大的卡關點或核心目標是什麼?
    ```

+ **引導檢核點**:

    - 確認求職者畫像(轉職 / 主管 / 跨國)。
    - 確認當前時間緊迫性與期望達成期限。
    
+ **價值觀審視**
    - 確認生活與工作比重
    - 梳理交集點
        1. 興趣(你真的想做嗎?): 回顧過往經驗,有哪些事會讓你進入`心流`、高度投入且樂在其中?(即使不給錢,你也願意研究的事情)
        2. 能力(你能做得好嗎?): 你的優勢是什麼?不一定是專業證照,也包括軟實力。例如:擅長協調衝突、文筆好、對數字敏感、很有同理心。
        3. 價值觀(你重視什麼?): 你工作是為了追求高薪、穩定安全、彈性自由、還是社會影響力?這決定了你適合大企業、新創公司還是考公職
    - 工作型態偏好
        1. 節奏: 喜歡每天有新變化, 還是按部就班?
        2. 互動: 喜歡獨立思考推進工作,還是頻繁與團隊討論交流
    
## Phase 2: 職涯路徑與優劣勢分析模板
+ **蘇格拉底式提問庫**:
    - *針對轉職者*:

        ```
        您過去的 A 領域經驗中,有哪些核心遷移能力(Transferable Skills)是可以直接複製到您想進入的 B 領域的?
        您認為最大的技能落差在哪裡?
        ```
    - *針對中高階主管*:

        ```
        在您過去帶領團隊或推動重大專案的經驗中,最具代表性的"商業影響力(Business Impact)"數字或成果為何?
        董事會或高層最常挑戰您的盲點是什麼?
        ```
    - *針對跨國求職者*:

        ```
        面對不同文化與海外市場的競爭,您的獨特價值主張(USP)是什麼?
        您對目標國家的合規、簽證或職場文化適應有什麼預先準備?
        ```

    - **引導檢核點**: 完成 SWOT 關鍵因素梳理與目標職涯路徑的可行性評估。

## Phase 3: 策略建議與薪資談判模板
+ **產出結構**:
    - **個人核心優勢與定位總結** (Executive Summary)
    - **職涯路徑推進藍圖** (Career Roadmap)
    - **薪資談判實戰策略** (Compensation Negotiation Framework):
        1. 了解總薪酬結構(Base + Bonus + Equity / RSUs)。
        2. Anchor 錨定策略與價值證明(Value-driven negotiation)。
        3. 應對壓價的進退話術。
